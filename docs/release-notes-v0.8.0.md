## 评论区与相关推荐

- B 站视频评论与相关推荐、网易云歌曲评论与相似歌曲，以及网易云播客节目评论。
- 选中歌曲按 `i` 看评论、`I` 看推荐；歌词页使用当前播放曲目。面板内 `Tab` 切换评论／推荐，`esc` 关闭。
- 评论自动换行，方向键或滚轮滚动，`PgUp` / `PgDn` 滚动一屏，`[` / `]` 翻页，`r` 重试。
- 推荐可 `enter` 播放、`E` 加入队列、`e` 下一首播放、`a` 加入歌单。
- 请求异步执行；关闭时取消，切换曲目或重新打开后，旧结果不会覆盖当前内容。接口失败不影响播放。
- 评论目前只读，不含发表评论、点赞、回复与楼中楼。B 站匿名访问可能只有少量预览，界面提示登录并停止无效分页。

## 用户、歌手主页与播客电台

- 网易云歌手主页支持多歌手选择、作品分页；用户主页可浏览公开歌单和「TA 的播客节目」。
- B 站接入 UP 主资料与投稿列表，支持从视频或空间链接进入。
- `N` →「网易云播客 / 电台」浏览热门电台、节目列表和主播主页；已登录账号可通过「我的主页」进入自己的公开主页。
- `N` →「打开主页 / 电台链接」接受网易云歌手、用户、歌单、电台链接及 B 站空间链接，也支持 `netease:artist:6452`、`netease:user:32953014`、`netease:radio:792544462`、`bilibili:user:122541` 等明确类型的引用。
- 节目可播放、加入队列或本地／混合歌单。节目身份保留为 `program:<节目ID>`，播放时解析对应音频，评论使用节目自己的资源；不会把节目混作普通歌曲写入网易云云端歌曲歌单。
- 支持节目链接与 `program:节目ID` 作为曲目目标。主页浏览目前只读，不含关注、订阅或付费购买。

### 纯键盘操作

| 按键／入口 | 行为 |
| --- | --- |
| `u` | 查看**当前播放曲目**的作者，与列表光标无关；多位作者先选择，只有一位时直接进入主页；暂停时仍可使用 |
| 评论区 `O`（大写） | 打开屏幕顶部评论的作者主页 |
| `N` →「选中歌曲的歌手 / 用户主页」 | 查看列表选中曲目的关联主页；歌曲菜单也提供「此曲的歌手 / 用户主页」 |
| 主页内 `↑` / `↓`、`enter` | 选择、进入子页面或播放 |
| 主页内 `[` / `]`、`backspace` / `b`、`esc` | 翻页、返回上层、关闭 |
| 主页内 `E` / `e` / `a` / `i` | 对可播放条目入队、下一首播放、加入歌单、看评论 |

`u` 在评论、推荐和主页浏览面板内也始终使用按键时的当前曲目。歌曲对应歌手、视频对应 UP 主、节目对应主播；所属电台不计为作者。无当前曲目或无可用作者时会提示。单作者直接进入后，返回不会经过多余的单项选择页。

命令面板 `N` 可从常规页面的非输入状态打开。新增动作 `comments`、`related`、`profiles`、`comment_author` 均可配置，默认分别为 `i`、`I`、`u`、`O`。详见[按键速查](reference/keys.md)、[快捷键配置](reference/keymap.md)与[曲库指南](guide/library.md)。

离线预览：`zero demo comments`、`zero demo related`、`zero demo profile`、`zero demo radio`。

## 同步调整与修复

- **登录态同步改为可选，默认关闭**，旧配置未写 `sync_accounts` 也按关闭处理。每台设备需单独启用：同步页开关、`zero sync accounts on` 或初始化时指定 `--sync-accounts`。
- 关闭时不上传或导入账号登录态，歌单、快捷键和可同步注释继续同步；不因未配置、过期或损坏的登录态密钥反复警告。关闭不会删除本机登录信息、缓存密钥或仓库已有密文与历史。
- 新仓库使用 `meta.v=3`，支持无口令初始化；首次开启登录态同步时再设置口令。已有 v2 加密仓库在普通同步或切换开关时保留 v2，更换口令时写入 v3。**参与 v3 仓库同步的设备必须使用支持 v3 的客户端。**
- 修复合法单曲注释路径被误判、导致仓库同步失败的问题，保留原有注释文件名，并覆盖 CLI / go-git 的导入、冲突与恢复流程。
- 系统 Git 与内置 go-git 共用快照、三方合并和恢复逻辑；通过 `auto` / `cli` / `gogit` 选择。每轮固定后端，认证或网络失败不会自动切换。
- 混合歌单里的歌曲排除记录会同步，另一设备仍会隐藏这些歌曲；排除不删除源歌单中的曲目。文件夹歌单、仅本机歌单、本地曲目注释与本地歌词绑定继续只留在本机。

详细设置、认证方式与升级边界见[跨设备同步](guide/sync.md)。歌单和注释快照继续沿用 v2 字段结构；新元数据版本 v3 用于表达可选的登录态加密，两者不要混淆。

## 共享核心与 GUI 准备

- 业务代码与终端界面拆分为独立 `zero-beat-core` / `zero-beat-tui` Go 模块，由集成仓库的子模块与 `go.work` 联调；core 不依赖 TUI、Bubble Tea、oto 或 DBus。
- core 新增可选 `CommentReader`、`RelatedRecommender`、`Browser` 接口，供 TUI 与未来 GUI 共用；GUI 不需要复制平台接口或 TUI 页面逻辑。
- GUI 的 Session、RPC、Flutter 界面与平台集成仍待实现。评论、推荐、主页、播客电台及默认关闭的登录态同步均纳入 GUI 接入范围；具体阶段见 [GUI 路线图](https://github.com/Sheyiyuan/zero-beat-gui/blob/main/docs/07-roadmap.md)。
- 0.8.0 暂缓发布，待 GUI 完成和联合验收后再发布。组件标签与应用打包顺序见[模块迁移与发布说明](monorepo-and-sync.md)。
